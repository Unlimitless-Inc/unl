# Security

## Reporting a problem

Please report a security problem privately, never in a public issue.

- On GitHub: open the **Security** tab of this repository and choose **Report a vulnerability**.
- Or by email: hello@unlimitless.ai, with "Security" in the subject.

Tell us what you found, how to reproduce it, and what it lets someone do. Do not include anyone's data, and do not test against an account that is not yours.

We will confirm we have your report, keep you told of what we find, and say when it is fixed. If you would like to be credited, say so.

## What this covers

The code in this repository: the `unl` command, the AI SDK package, the Cursor plugin, the examples and the decision format. Problems in the hosted service at `api.unlimitless.ai` are welcome through the same routes.

## Supported versions

Fixes go into the latest release of each package. Update to it before reporting.
